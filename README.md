**Платформа, где друзья тайно скидываются на подарок к дню рождения — вход через Telegram, вишлист именинника и секретный чат без ведома виновника торжества.**

## Зачем

Собрать друзей на общий подарок обычно значит: кто-то заводит чат, вручную вспоминает, у кого скоро день рождения, гадает, что дарить, и следит, чтобы именинник ничего не заметил. **BirthdayPlanner** делает это за вас. Каждый входит через Telegram, заполняет свой вишлист и подписывается на дни рождения друзей. За несколько недель до даты платформа сама уведомляет подписчиков, помогает создать **секретный чат для обсуждения подарка** и рассылает в него приглашение — а именинник об этом ничего не знает и просто видит поздравления в день Х.

## Возможности

- **Вход одним тапом через Telegram** — официальный Telegram Login Widget, подпись проверяется по HMAC, сессия — в HttpOnly-cookie с JWT. Ни паролей, ни отдельной регистрации.
- **Профиль и вишлист** — имя, дата рождения и аватар; список желаемых подарков с названием, описанием, ссылкой на магазин и фотографией. Фото ужимаются и переэнкодятся на сервере (EXIF снимается), отдаются только авторизованным.
- **Подписка на дни рождения друзей** — лента ближайших именинников, отсортированная по числу дней до даты; в один клик подписываетесь на нужного человека.
- **Секретный чат для подарка** — за настроенное число дней до даты бот предлагает организатору создать группу, добавить бота и разослать приглашение всем подписчикам. Именинник в этот чат не попадает.
- **Приватные группы** — свои закрытые группы с ролями admin/member и инвайт-ссылкой (её можно перевыпустить в любой момент — старая сразу перестаёт работать). Бот заранее уведомляет админов группы о дне рождения участника; если рядом с именинником нет других админов, за неделю предупреждаются все остальные участники.
- **Telegram-бот** — подтверждает подписки, ведёт организатора по шагам («создайте группу → пришлите ссылку → разослать»), отмечает, кто активировал бота, и уведомляет о новых событиях. Кнопки и ссылки идут через безопасный вебхук с секретным токеном.
- **Панель администратора** — список пользователей с блокировкой и удалением, дашборд ближайших дней рождения со статусом рассылки, ручная рассылка ссылки на группу, генерация тестовых пользователей.
- **Ежедневный планировщик** — APScheduler в 09:00 по настроенному часовому поясу проверяет, у кого день рождения через N дней, и запускает сценарий уведомлений. Повторная обработка одной даты исключена (`BirthdayEvent` с уникальным ключом).
- **Заботится о приватности именинника** — заблокированные и «тестовые» профили скрыты от обычных пользователей; аватары и фото вишлиста отдаются только по JWT, без публичной статики.
- **Готов к самостоятельному хостингу** — один `docker compose up`: PostgreSQL, FastAPI-бэкенд и React-фронтенд за Nginx. Схема БД управляется миграциями Alembic.

## Быстрый старт

Нужны Docker и Docker Compose, а также [бот в Telegram](https://t.me/BotFather) (`BOT_TOKEN`).

```sh
git clone https://github.com/chuck-uz/BirthdayPlanner.git
cd BirthdayPlanner
cp .env.example .env     # заполните BOT_TOKEN, JWT_SECRET_KEY и прочее (см. ниже)
docker compose up --build
```

Откройте **http://127.0.0.1/** — фронтенд поднимется на 80-м порту, API проксируется на бэкенд, PostgreSQL хранит данные в именованном томе. При старте контейнер сам прогоняет миграции (`alembic upgrade head`).

> **Уже была рабочая база (до перехода на Alembic)?** Один раз выполните
> `docker compose run --rm backend alembic stamp head`, иначе миграция попытается
> создать существующие таблицы. Подробности — в [backend/migrations/README.md](backend/migrations/README.md).

## Настройка

Все параметры задаются через переменные окружения (файл `.env` в корне, читается и Compose, и бэкендом).

| Переменная | Обязательна | Назначение |
|---|:---:|---|
| `BOT_TOKEN` | да | Токен бота от [@BotFather](https://t.me/BotFather). Используется и для Login Widget, и для API бота. |
| `JWT_SECRET_KEY` | да | Секрет для подписи сессионных JWT. Длинная случайная строка. |
| `DB_USER` / `DB_PASSWORD` / `DB_NAME` | да | Учётные данные PostgreSQL (Compose собирает из них `DATABASE_URL`). |
| `TELEGRAM_ADMIN_ID` | нет | Telegram ID администратора: доступ к веб-панели `/admin` и ведение сценария группы в ЛС. |
| `BIRTHDAY_NOTIFY_DAYS_BEFORE` | нет | За сколько дней до ДР запускать рассылку (по умолчанию 14). |
| `SCHEDULER_TIMEZONE` | нет | Часовой пояс ежедневной проверки в 09:00 (по умолчанию `Europe/Moscow`). |
| `TELEGRAM_WEBHOOK_BASE_URL` | нет | Публичный HTTPS-адрес — при старте на нём выставляется вебхук `…/api/telegram/webhook`. |
| `TELEGRAM_WEBHOOK_SECRET` | нет | Секрет в заголовке вебхука (рекомендуется в проде). |
| `CORS_ALLOW_ORIGINS` | нет | Разрешённые Origin через запятую (по умолчанию — локальная разработка). |
| `COOKIE_SECURE` | нет | `true` для продакшена по HTTPS (cookie только по защищённому соединению). |

Для входа через Telegram укажите боту домен сайта: в [@BotFather](https://t.me/BotFather) → `/setdomain`.

## Как это устроено

```
Telegram Login ──► FastAPI /api/auth/telegram ──► JWT в HttpOnly-cookie
                                                        │
React (Vite + Nginx)  ◄────── /api/* ───────►  FastAPI (async) ──► PostgreSQL (SQLAlchemy 2.0)
                                                        │
                          APScheduler (09:00) ─► сценарий ДР ─► Telegram Bot API ─► секретный чат
                                                        ▲
                        Telegram webhook (callback / my_chat_member / message)
```

- **Аутентификация:** подпись Telegram проверяется по HMAC-SHA256, затем выдаётся короткий JWT в HttpOnly-cookie; блокировка аккаунта проверяется на каждом запросе.
- **Сценарий дня рождения:** подписка → уведомление за N дней → организатор создаёт группу и присылает ссылку боту → бот рассылает приглашение подписчикам; всё состояние в БД, идемпотентно.
- **Файлы:** аватары и фото вишлиста хранятся вне публичной статики и отдаются только по JWT через единый модуль хранилища с защитой от path traversal и decompression bomb.

## Локальная разработка без Docker

```sh
# бэкенд
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
alembic upgrade head
uvicorn main:app --reload

# фронтенд (в другом терминале)
cd frontend
npm install
npm run dev
```

Тесты бэкенда: `cd backend && pytest`.

## Приватность

Данные живут только в вашей базе PostgreSQL. Наружу приложение обращается лишь к Telegram Bot API (для входа, бота и рассылок). Аватары и фото вишлиста отдаются исключительно авторизованным пользователям, заблокированные профили скрыты. Смысл сервиса — держать подготовку подарка в тайне от именинника: он не видит ни секретного чата, ни того, кто на него подписан.
