Всё для общего подарка — в одном месте

От напоминания о дате до секретного чата: без ручных списков и без спойлеров для именинника.

Вход через Telegram

Один тап — без паролей и регистрации. Подпись проверяется по HMAC, сессия в защищённой cookie.

Вишлист желаний

Что подарить — больше не загадка. Название, описание, ссылка на магазин и фото по каждому пункту.

Подписка на дни рождения

Лента ближайших именинников по дням до даты. Подписались — и не пропустите.

Секретный чат подарка

Бот помогает создать группу и рассылает приглашение всем подписчикам. Именинник в неё не попадает.

Напоминания заранее

За настроенное число дней бот сам поднимает событие и собирает друзей — ничего не забудется.

Приватность и админка

Фото и аватары — только по авторизации. Панель админа: пользователи, дашборд ДР, ручная рассылка.

Сюрприз — это часть архитектуры

Именинник не видит ни секретного чата, ни того, кто на него подписан. Данные живут только в вашей базе, наружу приложение ходит лишь в Telegram. Никаких чужих серверов и «мы обрабатываем ваши данные».

Как это работает

Четыре шага — и общий подарок готовится сам.

Вошли и подписались

Вход через Telegram, заполнили вишлист, подписались на дни рождения друзей.

Пришло напоминание

За N дней до даты бот поднимает событие и предлагает организовать подарок.

Собрались в чате

Создаётся секретная группа, бот рассылает приглашение всем подписчикам.

Поздравили вместе

Друзья выбрали подарок по вишлисту — именинник видит только поздравления.

Запустить у себя — одна команда

Нужны Docker и бот в Telegram. Полностью self-hosted: PostgreSQL, бэкенд и фронтенд поднимутся вместе.

# клонируем и настраиваем
git clone https://github.com/chuck-uz/BirthdayPlanner.git
cd BirthdayPlanner
cp .env.example .env  # впишите BOT_TOKEN и JWT_SECRET_KEY
docker compose up --build
# откройте http://127.0.0.1/
